# Drowned

- [`docs/gameplay_rhythm.md`](docs/gameplay_rhythm.md): esquiva, emboscadas, ondas variadas e recursos de fôlego.

- [`docs/title_and_dialogue.md`](docs/title_and_dialogue.md): título animado, tempestade, seleção simplificada, fades e caverna dos diálogos.

- [`docs/gameplay_audio.md`](docs/gameplay_audio.md): passivas, habilidades especiais (Q / botão direito), trilha dinâmica e validação da integração com o GitHub.

- [`docs/PROJECT_STRUCTURE.md`](docs/PROJECT_STRUCTURE.md): organização de pastas e convenções.
- [`docs/PLAYABLE_PROTOTYPE.md`](docs/PLAYABLE_PROTOTYPE.md): fluxo jogável e controles atuais.
- [`docs/TECHNICAL_REFERENCE.md`](docs/TECHNICAL_REFERENCE.md): arquitetura, sinais, colisões e referência de funções.
- [`docs/CUSTOMIZATION_GUIDE.md`](docs/CUSTOMIZATION_GUIDE.md): guia prático para modificar personagens, mapa, combate, interface e diálogos.
- [`docs/gdd/Drowned_Game_Design_Document.pdf`](docs/gdd/Drowned_Game_Design_Document.pdf): GDD visual consolidado, com visão, mecânicas, referências, roadmap e espaço reservado para lore.
- [`docs/gdd/Drowned_Game_Design_Document.docx`](docs/gdd/Drowned_Game_Design_Document.docx): versão editável do GDD.
